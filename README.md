# Nexo Whisper — Releases

Este repo es solo para alojar los binarios públicos de Nexo Whisper y el `appcast.xml` de Sparkle. **No contiene código fuente** — el source vive en `NexoStudioinc/nexo-whisper` (privado, distribuido a compradores Pro como cumplimiento de GPL v3).

## Descargas

- **Última versión**: [GitHub Releases — latest](https://github.com/NexoStudioinc/nexo-whisper-releases/releases/latest)
- **Todas las versiones**: [GitHub Releases](https://github.com/NexoStudioinc/nexo-whisper-releases/releases)
- **Página de descarga**: [nexowhisper.com/descargar](https://nexowhisper.com/descargar)

## Auto-updates (Sparkle)

La app verifica updates contra `appcast.xml` hosteado en este repo (próximamente vía GitHub Pages o `nexowhisper.com/appcast.xml`).

Cada release está firmada con la clave EdDSA de Nexo Whisper para que Sparkle valide autenticidad.

## Licencia

El **código fuente** de Nexo Whisper es GPL v3. Los compradores Pro reciben acceso al repo privado vía invite automático al pagar (cumplimiento GPL).

Los binarios distribuidos en este repo son del mismo código GPL v3 — podés descargarlos libremente. Las features Pro requieren license key activada para funcionar; sin licencia, la app queda en modo Free funcional indefinido.
